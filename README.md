# AIterior Design - Frontend Client

Modern AI-powered interior design web application built with React, Vite, and Tailwind CSS.

## Features
- AI-driven room design recommendations & visualization
- Portfolio and project showcases
- Responsive design with smooth animations
- Seamless backend API integration

## Tech Stack
- **Framework:** React + Vite
- **Styling:** Tailwind CSS + Lucide Icons
- **Deployment:** Vercel

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Update the backend API URL as required.

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
